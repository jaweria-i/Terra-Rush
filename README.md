# Terra Rush

Terra Rush is a 3D Endless Runner Game developed using Unity as a Final Year Project (FYP).

## Features

* Endless running gameplay
* Obstacle avoidance system
* Score tracking
* 3D environment and assets
* Interactive player controls

## Technologies Used

* Unity 3D
* C#
* Microsoft Visual Studio

## Project Description

The objective of Terra Rush is to provide an engaging endless runner experience where players avoid obstacles, achieve high scores, and navigate through a dynamic 3D environment.
